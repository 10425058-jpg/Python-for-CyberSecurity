## 078 — Timeline construction

**Reference implementation:**

```python
from datetime import datetime,timezone
events=[("a","2026-01-01T10:02:00Z"),("b","2026-01-01T17:01:00+07:00")]
def when(raw):
    return datetime.fromisoformat(raw.replace("Z","+00:00")).astimezone(timezone.utc)
assert [k for k,_ in sorted(events,key=lambda x:when(x[1]))]==["b","a"]
```

**Explanation:** Normalize aware timestamps before chronological ordering.

**Negative/boundary test:** Reject timestamps with no offset.

**Safety and constraints:** Preserve original source order and source clock uncertainty.
