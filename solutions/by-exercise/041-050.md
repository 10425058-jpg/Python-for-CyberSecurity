## Exercise 041 — pathlib inventory

```python
from pathlib import Path
from tempfile import TemporaryDirectory
with TemporaryDirectory() as td:
    root = Path(td)
    (root/"a.txt").write_text("lab",encoding="utf-8")
    files = [p.name for p in root.iterdir() if p.is_file()]
    assert files == ["a.txt"]
```

**Worked explanation:** Use pathlib for paths and inspect only approved local roots.

**Extend the tests:** Add a directory and verify it is excluded.

**Security boundary:** A path walk can race with symlink changes; this is not forensic acquisition.

**Student submission:** code, one successful and one unsuccessful case, a written interpretation, and a note on the limits of the example.

## Exercise 042 — Symlink awareness

```python
from pathlib import Path
from tempfile import TemporaryDirectory
with TemporaryDirectory() as td:
    root=Path(td)
    target=root/"target.txt"
    target.write_text("lab")
    link=root/"alias.txt"
    try:
        link.symlink_to(target)
    except (OSError, NotImplementedError):
        pass  # some Windows setups restrict symlinks
    else:
        assert link.is_symlink()
```

**Worked explanation:** A symlink can redirect a path away from its apparent location.

**Extend the tests:** Attempt symlink creation on Windows; report when permissions prevent it.

**Security boundary:** Check-then-open path validation is vulnerable to filesystem races.

**Student submission:** code, one successful and one unsuccessful case, a written interpretation, and a note on the limits of the example.

## Exercise 047 — Local-only TCP reachability

```python
import socket
with socket.socket(socket.AF_INET,socket.SOCK_STREAM) as s:
    s.bind(("127.0.0.1",0))
    s.listen(1)
    port=s.getsockname()[1]
    with socket.socket() as client:
        client.settimeout(1)
        assert client.connect_ex(("127.0.0.1",port))==0
```

**Worked explanation:** A local TCP listener accepts a handshake, which is only a reachability result.

**Extend the tests:** Stop the listener and note environment-dependent refused/timeout status.

**Security boundary:** Do not infer vulnerability or exploitability from an open port.

## Exercise 050 — Async cancellation cleanup

```python
import asyncio
async def work():
    try:
        await asyncio.sleep(10)
    finally:
        print("cleanup executed")
async def test():
    task=asyncio.create_task(work())
    await asyncio.sleep(0)
    task.cancel()
    try:
        await task
    except asyncio.CancelledError:
        pass
    assert task.done()
asyncio.run(test())
```

**Worked explanation:** Cancellation should unwind finally blocks and close resources.

**Extend the tests:** Cancel while holding a local temporary file or socket; check cleanup.

**Security boundary:** Avoid catching and suppressing cancellation without propagation.

**Student submission:** code, one successful and one unsuccessful case, a written interpretation, and a note on the limits of the example.
