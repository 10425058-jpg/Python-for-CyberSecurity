## 085 — Entropy calculation

```python
from math import log2
from collections import Counter
def entropy(raw):
    if not raw: return 0.0
    n=len(raw)
    return -sum((v/n)*log2(v/n) for v in Counter(raw).values())
assert entropy(b"AAAA")==0.0
assert entropy(b"ABAB")==1.0
```

**Step-by-step reasoning:** Calculate empirical Shannon entropy in bits per byte.

**Additional test or review:** Compare compressed benign bytes and repeated text.

**Cybersecurity interpretation:** High entropy is not a malware verdict.

**Acceptance:** rerun the assertion, add a negative/boundary test, and write a two-sentence explanation of what this demonstration cannot prove.
