## Answer study protocol

Read the original prompt, solve it independently, then compare your approach with the reference. Reproduce assertions and add a positive and negative test. Document source trust, limitations and complexity. Optional AEAD examples 055–056 require the vetted external cryptography package; all other snippets target the Python standard library.

These examples are educational and are not evidence of production security. A correct snippet may intentionally omit deployment-specific controls that must be designed independently.
