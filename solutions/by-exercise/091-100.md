## 094 — Cross-OS event normalization

```python
from datetime import datetime,timezone
def utc(text):
    value=datetime.fromisoformat(text.replace("Z","+00:00"))
    if value.utcoffset() is None: raise ValueError("offset")
    return value.astimezone(timezone.utc).isoformat()
assert utc("2026-01-01T17:00:00+07:00")=="2026-01-01T10:00:00+00:00"
```

**Step-by-step reasoning:** Normalize source timestamps while retaining original provider identity.

**Additional test or review:** Reject unknown provider codes; provider/event ID meaning is contextual.

**Cybersecurity interpretation:** Never merge events solely by numeric event ID.

**Acceptance:** rerun the assertion, add a negative/boundary test, and write a two-sentence explanation of what this demonstration cannot prove.

## 095 — SQLite event-id dedup

```python
import sqlite3
c=sqlite3.connect(":memory:")
try:
    c.execute("CREATE TABLE e(source TEXT,id TEXT,PRIMARY KEY(source,id))")
    c.execute("INSERT OR IGNORE INTO e VALUES (?,?)",("lab","1"))
    c.execute("INSERT OR IGNORE INTO e VALUES (?,?)",("lab","1"))
    assert c.execute("SELECT COUNT(*) FROM e").fetchone()[0]==1
finally:
    c.close()
```

**Step-by-step reasoning:** An explicit uniqueness constraint makes replay idempotency transactional.

**Additional test or review:** Insert same ID from a different source; both may be valid.

**Cybersecurity interpretation:** INSERT OR IGNORE requires an audited duplicate-handling policy.

**Acceptance:** rerun the assertion, add a negative/boundary test, and write a two-sentence explanation of what this demonstration cannot prove.

## 096 — Local parser fuzzing
