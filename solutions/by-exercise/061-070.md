## 061 — Parameterized SQLite

**Reference implementation:**

```python
import sqlite3
con=sqlite3.connect(":memory:")
try:
    con.execute("CREATE TABLE users(name TEXT)")
    con.execute("INSERT INTO users VALUES (?)",("alex",))
    suspicious="alex' OR 1=1 --"
    assert con.execute("SELECT * FROM users WHERE name = ?",(suspicious,)).fetchall()==[]
finally:
    con.close()
```

**Explanation:** Question marks keep input as SQL data rather than query syntax.

**Negative/boundary test:** Try a real username containing an apostrophe.

**Safety and constraints:** Parameterization does not provide authorization.

## 065 — SSRF destination controls

**Reference implementation:**

def permitted(url):
    value=urlsplit(url)
    return (value.scheme=="https"
            and value.hostname=="api.example.test"
            and value.port in (None,443)
            and value.username is None)

## 067 — Safe file upload policy

**Reference implementation:**

```python
from pathlib import Path
def sanitized_name(upload_id):
    if type(upload_id) is not str or len(upload_id)!=8 or not upload_id.isascii() or not upload_id.isalnum():
        raise ValueError("invalid storage ID")
    return Path("uploads")/(upload_id+".bin")

```

**Explanation:** Generate opaque storage names rather than trusting client filenames.
