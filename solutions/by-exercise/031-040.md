## 031 — Unittest fundamentals

```python
import unittest
class Demo(unittest.TestCase):
    def test_hash_length(self):
        from hashlib import sha256
        self.assertEqual(len(sha256(b"x").hexdigest()),64)
result = unittest.TestResult()
Demo("test_hash_length").run(result)
assert result.wasSuccessful()
```

**Reasoned answer:** An assertion encodes a behavior that can be rerun in CI.

**Boundary / failure test to add:** Change 64 to 63 and ensure the test fails.

**Security and limitations:** Line coverage alone does not mean security correctness.

## 035 — Negative input tests

## 036 — Dataclass models

## 037 — Protocol interfaces
