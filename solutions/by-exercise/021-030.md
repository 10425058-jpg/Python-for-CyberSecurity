## 021 — Safe text reading

```python
from pathlib import Path
from tempfile import TemporaryDirectory
with TemporaryDirectory() as td:
    f = Path(td)/"lab.txt"
    f.write_text("hello\n", encoding="utf-8")
    with f.open(encoding="utf-8", errors="strict") as stream:
        assert stream.readline(1025) == "hello\n"
```

**Reasoned answer:** Always specify encoding and enforce record size limits.

**Boundary / failure test to add:** Write invalid UTF-8 bytes and expect a UnicodeDecodeError.

**Security and limitations:** Read source evidence without overwriting it.

**Completion criterion:** explain the input/output contract; implement a second version without copying; report the actual result and one negative assertion.

## 022 — Chunked SHA-256

```python
from hashlib import sha256
from io import BytesIO
stream = BytesIO(b"sample")
h = sha256()
for chunk in iter(lambda: stream.read(2), b""):
    h.update(chunk)
assert h.hexdigest() == sha256(b"sample").hexdigest()
```

**Reasoned answer:** The same bytes hash identically regardless of chunk size.

**Boundary / failure test to add:** Change one source byte and compare output digests.

**Security and limitations:** A hash supports integrity comparison, not attribution.

**Completion criterion:** explain the input/output contract; implement a second version without copying; report the actual result and one negative assertion.

## 024 — JSONL streaming

```python
import json
from io import StringIO
source = StringIO('{"a":1}\n{"a":2}\n')
def records(lines):
    for line in lines:
        if len(line) > 1024:
            raise ValueError("line too long")
        yield json.loads(line)
assert sum(row["a"] for row in records(source)) == 3
```

**Reasoned answer:** Yield records one at a time instead of materializing a file.

**Boundary / failure test to add:** Send a malformed line and ensure the error is visible.

**Security and limitations:** A character cap after read is not a preallocation byte cap.

**Completion criterion:** explain the input/output contract; implement a second version without copying; report the actual result and one negative assertion.
