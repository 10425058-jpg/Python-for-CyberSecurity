## Exercise 051 — SHA-256 integrity

```python
import hashlib
a=hashlib.sha256(b"lab").hexdigest()
b=hashlib.sha256(b"lab!").hexdigest()
assert len(a)==64 and a!=b
```

**Worked explanation:** A digest summarizes bytes and can be compared with a trusted known digest.

**Extend the tests:** Compare original and copied files with chunked hashing.

**Security boundary:** Hash equality alone does not prove file origin or author.

**Student submission:** code, one successful and one unsuccessful case, a written interpretation, and a note on the limits of the example.

## Exercise 052 — HMAC tag verification

```python
import hmac,hashlib
key=b"lab-only-key"
message=b"synthetic"
tag=hmac.new(key,message,hashlib.sha256).digest()
assert hmac.compare_digest(tag,hmac.new(key,message,hashlib.sha256).digest())
assert not hmac.compare_digest(tag,hmac.new(key,b"changed",hashlib.sha256).digest())
```

**Worked explanation:** A shared secret authenticates message integrity within holders of the key.

**Extend the tests:** Try wrong key and modified message; both fail.

**Security boundary:** Shared-key tags do not uniquely identify which holder created a message.

## Exercise 057 — Nonce lifecycle design

```python
class MonotonicNonce:
    def __init__(self):
        self.next_value=0
    def take(self):
        if self.next_value >= 2**96:
            raise OverflowError("nonce exhausted")
        out=self.next_value.to_bytes(12,"big")
        self.next_value+=1
        return out
n=MonotonicNonce()
assert n.take()!=n.take()
```

**Worked explanation:** A monotonically increasing counter gives uniqueness within one instance.

**Extend the tests:** Restart the object and observe repeated values; persistent state is essential.

**Security boundary:** Real distributed writers require coordination or distinct nonce partitions.

**Student submission:** code, one successful and one unsuccessful case, a written interpretation, and a note on the limits of the example.

## Exercise 060 — Key rotation plan

```python
from dataclasses import dataclass
@dataclass(frozen=True)
class KeyMetadata:
    key_id:str
    status:str
metadata=[KeyMetadata("v1","decrypt-only"),KeyMetadata("v2","encrypt-and-decrypt")]
assert metadata[1].status=="encrypt-and-decrypt"
```

**Worked explanation:** Versioned metadata allows new encryption with v2 while retaining authorized decryption with v1.

**Extend the tests:** Model what happens if v1 key is lost before all ciphertext is migrated.

**Security boundary:** Store protected key material in KMS; a metadata list is not secret management.
