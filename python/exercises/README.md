# Independent Python Foundations Exercises — Chapters 01 and 02

This directory contains **50 standalone exercises**, each with a specific expected result and verification requirement. Work through them without copying reference answers.

- [Chapter 01 — 25 Language Foundations exercises](01-LANGUAGE-FOUNDATIONS-EXERCISES.md): objects, assignment, numeric types, Unicode, control flow, comprehension, closures, schema validation.
- [Chapter 02 — 25 Data Structures & Algorithms exercises](02-DATA-STRUCTURES-ALGORITHMS-EXERCISES.md): collections, recurrence, sorting/searching, graphs, shortest paths, DP, bounded detection.

Submit `exercise.py`, `test_exercise.py`, and a short explanation of why the solution works and what its failure boundary is. Read the [separate solution-key index](../solutions/README.md) only after attempting a problem.

**Project integration:** [two graded local programs and exact terminal commands](../../projects/foundations/README.md).
